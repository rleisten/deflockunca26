How the data is used and shared

What is collected
Each camera photographs passing vehicles and records the license plate, vehicle make, type and color, distinguishing features, plus the time and location. flocksafety.com
Where it is stored
Images and extracted data are sent to Flock’s cloud, not kept only on campus. flocksafety.com
How long it is kept
Flock’s stated default is deletion after 30 days. Each campus can set their own retention rules, as well as request extensions. DEFLOCK ILM
Who can search it
Flock, as well as Rekor and Axon, allow customers to create and set up an unlimited amount of Authorized users. DEFLOCK ILM
Who it is shared with
Flock lets each customer choose whether to share its data with other agencies’ networks (local, state, national). DEFLOCK ILM
Oversight
Flock keeps search audit logs. These logs are not freely available to the public.
